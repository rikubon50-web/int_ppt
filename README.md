# スライド結合（int_ppt）

複数の PowerPoint ファイルを、**見た目そのまま**で 1 つの pptx に結合する Windows 用ツールです。
`スライド結合.vbs` の 1 ファイルだけで動きます。

## 特長

- 📎 **ドラッグ＆ドロップで結合** — 結合したい pptx を選んで、`スライド結合.vbs` のアイコンにまとめて重ねるだけ。
- 🎨 **見た目そのまま** — PowerPoint を COM 連携で操作し、各スライドの体裁を保ったまま取り込みます。
- 🔤 **追加インストール不要** — Windows 標準の WSH（Windows Script Host）と PowerPoint だけで動作します。
- 🗂 **ファイル名順に結合** — ドロップした順番に関係なく、ファイル名（大文字小文字を区別しない）の昇順で並べて結合します。
- 🛟 **元ファイルは無変更** — 読み込むだけで、元の pptx には一切手を加えません。
- 🈶 **文字化けしない** — スクリプト本体は純 ASCII で記述し、日本語 UI は実行時に Unicode から生成しています。

## 動作環境

- Windows（Windows Script Host は標準搭載）
- Microsoft PowerPoint（デスクトップ版）がインストールされていること
- 対応形式：`.pptx` / `.ppt` / `.pptm`

## 使い方

1. 結合したい PowerPoint ファイルを複数選択します。
2. 選んだファイルを、`スライド結合.vbs` のアイコンの上へまとめてドラッグ＆ドロップします。
3. PowerPoint が起動し、全スライドが 1 つに結合されます。
4. 完了するとダイアログが表示され、出力先を知らせます。

### 出力

- **場所**：最初のファイル（ファイル名順で先頭になるファイル）と同じフォルダー
- **ファイル名**：`結合スライド_YYYYMMDD_HHMMSS.pptx`（実行した日付・時刻）

例）`a.pptx` `b.pptx` `c.pptx` を結合すると、`a.pptx` と同じフォルダーに
`結合スライド_20260604_134437.pptx` のようなファイルが作成されます。

結合後のファイルは PowerPoint で開いたままになるので、その場で内容を確認できます。

## 補足・仕様

- **結合順序**：ドロップした順番ではなく、**ファイル名の昇順**で結合します。意図した順に並べたい場合は、`01_`, `02_` のようにファイル名へ連番を付けてください。
- **対応外のファイル**：`.pptx` / `.ppt` / `.pptm` 以外をドロップした場合は無視されます。
- **開けなかったファイル**：破損などで取り込めなかったファイルがあった場合は、結合は続行し、完了ダイアログにそのファイル名を表示します。
- **元ファイル**：開いて読み込むだけで保存はしないため、内容・更新日時ともに変化しません。
- **スライドサイズ**：先頭ファイルのスライドサイズ（縦横比）が結合後にも引き継がれます。

## うまく動かないとき

| 症状 | 対処 |
| --- | --- |
| 「PowerPoint を起動できませんでした」と出る | デスクトップ版 PowerPoint がインストールされているか確認してください。 |
| 何も起きない／文字が変 | `スライド結合.vbs` を右クリック →「プログラムから開く」で Microsoft Windows Based Script Host が選ばれているか確認してください。 |
| 結合順がおかしい | ファイル名の昇順で結合されます。連番を付けて並びを整えてください。 |

## 仕組み（開発者向け）

`スライド結合.vbs` は VBScript（WSH）で書かれています。

- `WScript.Arguments` で受け取ったドロップ先のパスから、対応拡張子のファイルだけを抽出。
- ファイル名で昇順ソート。
- 先頭ファイルを `Presentations.Open` でベースとして開き、残りを `Slides.InsertFromFile` で末尾に追記（体裁を保持）。
- `SaveAs`（`ppSaveAsOpenXMLPresentation = 24`）で `.pptx` として出力。
- 日本語文字列はすべて Unicode コードポイントから `ChrW` で生成しているため、ソースは純 ASCII を維持し、保存時のエンコードに関係なく文字化けしません。
